# Industry-fit sections & features — what to ADD to lift conversion

Purpose: an audit isn't only "fix what's broken" — it's also **"what proven
section/feature is this store MISSING for its category that would lift
conversion?"** Classify the store, then propose the **1–3 highest fit×impact
additions** (never dump the whole list). Frame each as an opportunity, classify
feasibility (theme section/block/setting, or app-dependent → flag), and cite a real
store that does it well. Each addition is a normal finding with its own per-finding
mockup unless it's clearly out of scope (then note it under Global Notes /
High-Impact). Prefer additions that fit the store's real catalogue and brand — not
generic bolt-ons.

---

**Suggest by category fit — not a universal checklist.** Classify the store's
industry and real catalogue FIRST; only propose sections that genuinely fit it and
that the store is missing. This whole file is a *menu to pick from by fit* — a
spec/comparison table fits electronics/supplements but not a single-SKU candle brand;
a size/fit finder fits apparel but not homeware; a fitment selector fits auto/tools
only. Don't file a suggestion because it's "best practice" — file it because it fits
this category and is absent. One well-fit addition beats three generic bolt-ons; if
nothing extra fits the niche, add none.

**Sweep every audited page (page-fit = category-fit).** Well-fit additions live on
different pages — so on each captured page ask "what section does THIS store's
category need here that's missing?" and spread suggestions across the pages they
belong to rather than clustering them all in the cart. Skip a page if nothing fits.

## Near-universal essentials (check presence first — suggest ONLY if missing AND relevant)
*These apply broadly, but still gate on fit: only flag one if the store lacks it and
it makes sense here — e.g. free-ship progress only if a threshold exists, search only
for a large catalogue, wishlist only for considered purchases. Don't suggest a
present feature or an irrelevant one.*
- **Social proof** — star ratings on cards + a reviews section on the PDP (Q&A, photos, verified badge).
- **Mobile sticky Add-to-Cart** — persistent ATC + price bar on the PDP when the buy box scrolls off.
- **Free-shipping threshold progress** — "you're €X away from free shipping" in cart/drawer (if a threshold exists).
- **Trust near the ATC** — shipping, returns, warranty, secure-checkout, payment badges at the decision point.
- **Prominent search** — especially for large catalogues (predictive/instant search).
- **Objection-handling** — an FAQ block, sizing/compatibility answers, delivery-time promise.
- **Recently viewed** + **wishlist/save** for considered purchases.
- **Breadcrumb navigation** on every non-homepage page (Collection, PDP, and any
  static/policy page) — "Home / Collection / Product" wayfinding, missing on a
  surprising number of themes. Cheap, theme-native, always check for it.

## Cross-industry homepage section menu (pick by fit, not a checklist)

Beyond the hero, a well-built homepage tends to draw from this menu of proven
section TYPES — industry-agnostic, so gate every pick the same way as the category
playbooks below: only suggest one the store is missing AND that fits its brand/
content reality (e.g. don't suggest a blog section for a store with no blog; don't
suggest testimonials if the store has no reviews yet to feature).
- **Testimonials** — a curated quote/review strip (distinct from the PDP reviews
  module) — good social proof directly on the homepage.
- **Blog posts** — a "from the blog" row, but ONLY if the store actually has a blog.
  Check before suggesting: fetch `/sitemap.xml` (or the theme's blog-specific sitemap,
  e.g. `/blogs/news/sitemap.xml`) for blog article URLs, or look for a Blog/News/
  Journal link in the nav or footer. Don't suggest a blog section for a store with no
  blog content — that's a bigger ask than a theme section.
- **Trust section** — a dedicated trust/USP band (shipping, returns, guarantee,
  payment security) distinct from a thin icon row — good when trust signals are
  currently scattered or absent.
- **Image with text** — an editorial half-image/half-copy row (brand story, a
  featured collection's rationale, a how-it-works step) — good for adding narrative
  without a full "About" page detour.
- **Hero video** — a looping product/lifestyle video in the hero or just below it,
  when the brand has (or plausibly could produce) motion content that a static photo
  can't convey (e.g. a product in use, an in-store/on-location moment).
- **Full-width banner** — a single promotional strip (a sale, a category, a seasonal
  push) — see the hero-type menu in `shopify-ecommerce-redesign` for composition; keep
  it to ONE per homepage pass unless there's a real second campaign to carry, and
  don't stack it directly against another full-bleed band (rhythm — alternate with a
  grid/text section, see the "Conversion flow" check above).
- **Collection list** — a grid of category entry tiles (the store's real top-level
  categories) — usually the highest-leverage addition when a homepage buries product
  discovery behind other content (see the "too many low-value sections before
  product discovery" common issue above).
- **Brand section** — a "shop by brand" logo strip, when the store's catalogue is
  genuinely multi-brand and the brand names carry trust/recognition (real logos on
  neutral backgrounds — never invent or restyle a brand's mark).
- **Newsletter** — an email-capture block (often folded into the footer rather than
  a standalone homepage section — check it isn't already covered before suggesting a
  second one).
- **Featured products** — a bestsellers/new-arrivals/curated row (distinct from the
  Collection page) — one of the most common genuinely-missing sections; almost
  always a well-fit addition when absent.

This list isn't exhaustive — propose other section types when they genuinely fit
this store's brand and content (e.g. a size/spec comparison teaser, a founder-story
band, a press/"as seen in" strip). The bar is the same as everywhere else in this
file: fit × impact × feasibility, 1-3 picks, never a dump of the whole menu.

## Electronics / tech / smart-home
- Spec **comparison table** (this vs other models) + a **"which is right for me?" chooser/quiz**.
- **Compatibility / "works with"** block (ecosystems, apps, voice assistants, standards e.g. Zigbee/Matter).
- **What's in the box** + **setup-in-3-steps**; warranty + support badges.
- **Demo video / feature GIFs**, app screenshots.
- **Bundles** (device + accessory) and cross-sell of consumables/accessories.
- Reviews with verified badge + **Q&A**; UGC.

## Fashion / apparel
- **Size guide + fit finder** (true-to-size, model height/size worn); size chart in the buy box/drawer.
- Rich **variant swatches** (colour + per-variant image); **"complete the look"** outfitting — see "Color/variant swatch quality" in the main skill for the concrete checklist (visual chips not text dropdown, per-variant image swap, sold-out treatment, cross-page consistency).
- **Fabric / care / material** details; sustainability notes.
- **UGC / lookbook**, model-on gallery, review **fit feedback** (runs small/large).
- Emphasise **free returns/exchange**; easy size-exchange.

## Beauty / skincare / cosmetics
- **Shade / skin-type finder**; **before/after**; **ingredient list + "free-from"**. Shade options are also a variant-swatch case — apply the same swatch-quality checklist (visual chips, per-variant image, sold-out treatment).
- **How-to-use routine**; **subscription / replenishment**.
- Reviews filterable by skin type; UGC; derm/clinical claims.
- **Bundles / routines / kits**; samples.

## Food / beverage / consumables
- **Subscription & "subscribe & save"**; easy reorder/replenish.
- **Flavour/variety selection**, **bundle builder**; nutrition / ingredients / allergens.
- **Recipes / usage** content; freshness / shipping (cold-chain) reassurance.
- Reviews + taste feedback.

## Home / furniture / decor
- **Room / lifestyle imagery + "shop the room"**; **dimensions** + AR/room-view.
- **Material / care**; **delivery & assembly** info; **financing**.
- **Swatch / sample** ordering; **bundles / sets**; warranty. Fabric/finish colour options are a variant-swatch case too — apply the swatch-quality checklist.

## Jewelry / watches / luxury
- Rich detail (materials, dimensions, **certification**); **gift packaging + engraving**.
- Trust: authenticity, warranty, secure shipping, **financing**; size guide (ring/band).
- Editorial / brand story; reviews + UGC; restrained premium design.

## Supplements / health
- **Ingredient / dosage + benefits**; **third-party / clinical testing** badges.
- **Subscription**; **bundles / stacks**; **goal-based finder**; reviews with results.
- Compliance-safe claims.

## Collectibles / hobby / niche
- **Condition / grading detail + authenticity**; scarcity / new-arrivals cadence.
- **Filter by the axis buyers shop** (grade, era, franchise, set); wishlist / back-in-stock alerts.
- Community / social proof; secure-packaging emphasis.

## Tools / auto / B2B
- **Fitment / compatibility** (vehicle/model selector); **bulk / volume pricing**; **spec sheets / downloads**.
- **Trade / quote flow**; stock + lead time; reorder; datasheets.

---

## How to recommend
1. Start from the **cross-category essentials** — the fastest, highest-fit wins on almost any store.
2. Add **1–2 from the store's category playbook** that match its real catalogue and price point.
3. Rank by **fit × impact × feasibility**; pick the top 1–3. Note app-dependent ones explicitly.
4. Write it as an opportunity ("Add a spec-comparison table so shoppers can choose between models → fewer bounces to marketplaces"), with `reference_examples` and a per-finding mockup.
