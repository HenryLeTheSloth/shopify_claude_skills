# Shopify Ecommerce Website Audit Checklist

## Audit Objective

Audit the ecommerce website from a UI/UX, Ecommerce Features, Product Discovery, Conversion Optimization, and Customer Journey perspective.

For each checklist item, provide:

* Status: PASS / PARTIAL / FAIL
* Score: 0-5
* Notes
* Improvement Suggestions

---

# Auditor Instructions

Focus on:

1. Ease of navigation
2. Product discoverability
3. Shopping convenience
4. Conversion optimization
5. Mobile usability
6. Revenue-driving features
7. Trust-building elements
8. User friction points

Prioritize recommendations that can directly improve:

* Conversion Rate
* Average Order Value (AOV)
* Customer Retention
* User Experience
